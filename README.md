# CineMatch — Your Personal Movie Recommendation System

## Project Overview
CineMatch is a movie recommendation web application developed using Python, Flask, MySQL, HTML, and CSS. It helps users explore movies, search for titles, rate movies, and receive personalized movie recommendations.

## Objectives
- Provide a simple and user-friendly movie browsing experience.
- Allow users to search for movies.
- Recommend movies based on user preferences and ratings.
- Store movie details and user ratings in a MySQL database.

## Technologies Used
- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Features
- User registration and login
- Movie search
- Movie recommendations
- Movie ratings
- Favorite genre preferences
- Watchlist management
- Movie details and posters
- Rating history

## Project Structure
- `app.py` — Flask web application
- `main.py` — Additional Python application code
- `templates/` — HTML templates
- `static/` — CSS and other static files
- `.gitignore` — Files excluded from Git tracking
- `README.md` — Project documentation

## How to Run the Project
1. Install Python and MySQL.
2. Install the required Python packages.
3. Configure your database settings in a local `.env` file.
4. Create and configure the `movie_recommendation` database.
5. Run the Flask application using:

   `python app.py`

6. Open the local URL displayed in the terminal in your web browser.

## Conclusion
CineMatch provides a convenient way to explore movies and discover recommendations based on user preferences. The project demonstrates the use of web development, database connectivity, and recommendation functionality.
